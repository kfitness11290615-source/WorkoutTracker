# クラウド公開への手順（Microsoft Azure）

このアプリ（WorkoutTracker）をインターネット上に公開し、PCがオフの状態でも24時間スマホからアクセスできるようにする手順です。
無料で利用できる **Microsoft Azure（アジュール）** の機能（App Service）を使用します。

---

## ステップ1: Azureアカウントの作成
1. [Microsoft Azure 公式サイト](https://azure.microsoft.com/ja-jp/free/) にアクセスします。
2. 「無料で始める」をクリックし、Microsoftアカウントでログインしてアカウントを作成します。
   * ※無料枠を利用するための身分証明としてクレジットカードの登録が必要ですが、勝手に課金されることはありません。

## ステップ2: Webアプリ（サーバー）の作成
1. Azureポータル画面（管理画面）にログインします。
2. 画面上部の検索バーで「**App Services**」を検索して開きます。
3. 「＋ 作成」 > 「Web アプリ」をクリックします。
4. 以下の通りに設定し、画面下の「確認および作成」を押してから「作成」をクリックします。
   * **サブスクリプション**: (デフォルトのままでOK)
   * **リソースグループ**: 新規作成をクリックし、適当な名前（例: `workout-rg`）を入力
   * **名前**: アプリのURLの一部になります（例: `my-workout-tracker` とすると `https://my-workout-tracker.azurewebsites.net` になります）
   * **公開**: `コード`
   * **ランタイム スタック**: `.NET 9 (STS)` または `.NET 8`
   * **オペレーティング システム**: `Windows` （※SQLiteのデータベースファイルを安全に保存・更新するため、LinuxではなくWindowsを選んでください）
   * **地域**: `Japan East` などの日本リージョン
   * **価格プラン**: `Free F1`（無料枠）が選択されていることを必ず確認してください

## ステップ3: アプリの公開（VS Codeを使った最も簡単な方法）
VS Codeの拡張機能を使うと、クリックだけでアップロードが完了します。

1. VS Codeの左側のバーにある「拡張機能（ブロックのアイコン）」をクリックします。
2. 検索バーで「**Azure Tools**」を検索し、インストールします。
3. インストールが終わると、左側のバーに「Azure（Aのアイコン）」が追加されるのでクリックします。
4. 「Sign in to Azure...」をクリックし、ステップ1で作ったアカウントでサインインします。
5. サインイン後、VS CodeのAzureパネル内に「App Services」という項目があり、その中にステップ2で作ったアプリ名（例: `my-workout-tracker`）が表示されます。
6. そのアプリ名を **右クリック** し、「**Deploy to Web App...**」を選択します。
7. 「Select the folder to zip and deploy」と聞かれたら、現在開いている `WorkoutTracker` フォルダを選択します。
   * ※もし「Required configuration to build and deploy...」のようなメッセージが出たら「Yes」を押してください。
8. 画面右下にデプロイの進行状況が表示されます。数分待つと完了し、「Browse Website」というボタンが出るのでクリックします。

---

## ステップ4: アクセスと認証設定
1. ブラウザが立ち上がり、あなたのアプリが表示されます！
2. Basic認証のログインダイアログが表示されたら、設定したユーザー名とパスワードを入力してください。
   * **設定方法**:
     * **方法A（推奨: Azure ポータル）**: Azure ポータルの「環境設定（環境変数）」で `BasicAuth__Username` と `BasicAuth__Password` に任意のユーザー名・パスワードを設定します。
     * **方法B（ローカル設定）**: `appsettings.json` の `BasicAuth` セクションにユーザー名・パスワードを設定してからデプロイします。
3. 無事に画面が表示されたら、スマホのブラウザで同じURL（例: `https://my-workout-tracker.azurewebsites.net`）を開いてログインし、ホーム画面に追加（PWA風に利用）しておきましょう。

以上で完了です！
（認証情報を変更したい場合は、Azure ポータルの環境変数を更新するか、`appsettings.json` を更新して再デプロイしてください）
