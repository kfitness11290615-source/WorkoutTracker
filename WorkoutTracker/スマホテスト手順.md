# スマートフォンでのテスト手順

PCで起動しているWebアプリ（Blazor）に、同じWi-Fiネットワークに接続しているスマートフォンからアクセスしてテストするための手順です。

## 1. アプリをネットワークに公開する設定に変更する
デフォルトでは、`dotnet run` で起動したアプリは `localhost`（PC自身）からしかアクセスできません。
スマホ（外部）からアクセスできるようにするため、設定を変更します。

### 手順
プロジェクト内にある `Properties/launchSettings.json` を開きます。
（※Visual Studioから開く場合は、ソリューションエクスプローラーの「Properties」フォルダの中にあります）

中にある `https` および `http` のプロファイルの `applicationUrl` を以下のように変更します。（すでに複数URLが設定されている場合は、その後ろに追記するか変更します）

**変更前（例）:**
`"applicationUrl": "https://localhost:5001;http://localhost:5000"`

**変更後（例）:**
`"applicationUrl": "https://0.0.0.0:5001;http://0.0.0.0:5000"`

※ `0.0.0.0` にすることで、PCのネットワークIPアドレスからのアクセスを受け付けるようになります。

---

## 2. PCのIPアドレスを確認する
スマホからアクセスするには、PCの「IPアドレス」を知る必要があります。

### Windowsでの確認方法
1. キーボードの `Windowsキー + R` を押し、「ファイル名を指定して実行」を開きます。
2. `cmd` と入力してEnterを押し、コマンドプロンプトを開きます。
3. コマンドプロンプトに `ipconfig` と入力してEnterを押します。
4. 表示された結果の中から、**「IPv4 アドレス」** を探します。
   （例：`192.168.1.5` などの数字です）
   この数字をメモしてください。

---

## 3. アプリを起動する
Visual Studio の「開始（デバッグなしで開始）」ボタン、またはターミナルで `dotnet run` を実行してアプリを起動します。

---

## 4. スマホからアクセスする
1. PCと同じWi-Fiネットワークにスマホを接続します。（※これを行わないとアクセスできません）
2. スマホのブラウザ（Safari や Chrome など）を開きます。
3. アドレスバーに、先ほどメモしたIPアドレスとポート番号を入力します。

入力例（IPアドレスが `192.168.1.5`、ポート番号が `5000` の場合）：
`http://192.168.1.5:5000`

※ 最初のうちはHTTPS（`https://...:5001`）でアクセスすると、スマホ側で「証明書が無効です」といった警告画面が出ることがあります。その場合はHTTP（`http://` と ポート `5000` などのHTTP用ポート）でアクセスするとスムーズです。

これでPC上で動いているアプリがスマホの画面に表示され、操作感やレイアウト（片手入力のしやすさなど）を実際の端末でテストできます！
